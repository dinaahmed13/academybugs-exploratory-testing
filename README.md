# Exploratory Testing & Bug Hunting – AcademyBugs

## Project Overview

This project demonstrates practical exploratory and functional testing on the AcademyBugs e-commerce web application.

The objective was to explore the application from a QA perspective, identify unexpected behavior, and document defects with clear reproduction steps and supporting evidence.

## Testing Scope

The testing covered:

* Product Search
* Product Details
* Shopping Cart
* Checkout
* User Registration
* User Account
* UI and Usability
* Negative Testing

## Testing Types

* Exploratory Testing
* Functional Testing
* UI Testing
* Usability Testing
* Negative Testing

## Defects Identified

During the exploratory testing session, **18 defects were identified and documented**.

Each defect includes:

* Bug ID
* Bug Title
* Preconditions
* Steps to Reproduce
* Test Data
* Expected Result
* Actual Result
* Severity
* Priority
* Attachments \ Supporting Evidence
